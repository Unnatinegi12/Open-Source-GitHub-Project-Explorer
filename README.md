# 🚀 Open Source GitHub Project Explorer

A modern React application that helps users discover and explore open-source GitHub repositories. Users can search repositories, filter results, sort by popularity, bookmark favorites, add personal notes, and view repository statistics.

---

## 📌 Features

- 🔍 Search GitHub repositories
- 🌐 Filter repositories by programming language
- ⭐ Sort repositories by stars or last updated
- 📊 Statistics dashboard
- 🔖 Bookmark favorite repositories
- 📝 Add personal notes for repositories
- 💾 Local Storage support for bookmarks and notes
- 📱 Responsive user interface
- 🎨 Clean and modern UI using Tailwind CSS

---

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- Axios
- React Icons
- GitHub REST API
- Local Storage

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Unnatinegi12/Open-Source-GitHub-Project-Explorer.git
```

Navigate into the project

```bash
cd Open-Source-GitHub-Project-Explorer
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
